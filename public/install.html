Install InkVault on your tablet

This gives you a fullscreen app with no browser bars and much smoother handwriting: browsers only send a page the pen's full speed over a secure connection.

1Secure connection works

This tablet trusts your InkVault server.

2Install the app

In Chrome, tap the ⋮ menu → Install app (or Add to Home screen → Install).

Tap Share → Add to Home Screen.

Then open InkVault from your home screen.

Open the tablet page

1Download the certificate

It lets this tablet trust your own InkVault server. It is created by your server and works only for it.

Download certificate

Certificate name: …

2Install it

  1. Open Settings and search for “CA certificate”.
  2. Tap CA certificate → Install anyway.
  3. Pick InkVault-CA.crt from Downloads.
Can't find it?
  • Samsung: Settings → Security and privacy → More security settings → Install from device storage → CA certificate.
  • Pixel / most others: Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate.
  • Android may ask you to set a screen lock first. That's required for installing any certificate.
  1. Open Settings → Profile Downloaded → Install.
  2. Then Settings → General → About → Certificate Trust Settings and turn on the InkVault certificate.
